Play your own samples. Put one per line: URL note [loopStart] [loopEnd]

Using the built-in harmonium sample.

How it works
  • note is the pitch the recording plays, such as D4, C#3 or a MIDI number (middle C is C4 = 60). Each key plays the nearest sample, bent to pitch, so several samples across the range sound more natural than one.
  • loopStart and loopEnd (seconds) mark the steady part that repeats while a key is held. Optional; the default loops from 0.5 s to the end.
  • The list is saved in this browser and the samples are downloaded into memory again at each visit.
  • The server must allow cross-origin requests (CORS) and use https. Many file-sharing pages do not; GitHub Pages and most CDNs do.
  • Picked files must have the note in the file name, like harmonium_D4.wav.
  • Only use samples you have the right to use.
